📖 Overview
This repository documents my learning journey in Java Spring Boot Microservices, exploring how independent services communicate, discover each other, handle failures, and maintain system reliability.

The focus is on understanding modern backend architecture and implementing essential microservices design patterns.

📚 Topics Covered
01. Microservices Fundamentals
Microservices Fundamentals & Architecture
Understanding microservices concepts, system design, and independent services.
02. Service Communication
Synchronous vs Asynchronous Communication
Exploring different communication patterns between distributed services.
RestTemplate, RestClient & OpenFeign
Implementing HTTP-based communication between microservices.
Advanced Feign Client Features
Exploring advanced Feign configurations and request handling.
03. Service Discovery & API Management
Service Discovery using Netflix Eureka
Implementing automatic service registration and discovery.
API Gateway Architecture & Implementation
Managing API routing and centralized access to microservices.
04. Resilience & Fault Tolerance
Resilience & Fault Tolerance
Building reliable services that can handle unexpected failures.
Retry Pattern, Rate Limiter & Circuit Breaker
Managing service failures, controlling traffic, and preventing cascading errors.
Time Limiter & Bulkhead Pattern
Handling request timeouts and isolating service failures.
05. Observability & Monitoring
Observability & Distributed Tracing
Monitoring service performance and tracking requests across distributed systems.
Distributed Tracing using Jaeger
Visualizing request flows and identifying performance bottlenecks.
